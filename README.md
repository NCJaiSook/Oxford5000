# 🎓 Oxford 5,000 Vocab Master

เว็บแอปพลิเคชันสำหรับการเรียนรู้ จดจำ และฝึกฝนคำศัพท์ภาษาอังกฤษ **5,943 คำ** จากมาตรฐาน **Oxford 5000™** ออกแบบมาเพื่อให้ผู้เรียนพัฒนาทักษะภาษาอังกฤษได้อย่างเป็นระบบ มีประสิทธิภาพสูง ใช้งานได้ทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน พร้อมสำหรับการ Deploy ขึ้น **GitHub Pages** ได้ทันทีโดยไม่ต้องตั้งค่า Backend หรือเซิร์ฟเวอร์ใด ๆ เพิ่มเติม!

## ✨ คุณสมบัติเด่น (Key Features)

### 1. 📚 คลังคำศัพท์ Oxford 5,000 ครบครัน
- บรรจุคำศัพท์ระดับมาตรฐานสากล **A1, A2, B1, B2 และ C1**
- **คำอธิบายภาษาอังกฤษ (Oxford Definition)** ชัดเจน ตรงตามบริบท
- **คำแปลและความหมายภาษาไทย (Thai Definition)** ละเอียด กระชับ เข้าใจง่าย อ้างอิงจากฐานข้อมูล LEXiTRON
- **ตัวอย่างประโยคการใช้งานจริง (Example Sentences)** ช่วยให้เข้าใจบริบทและการนำไปใช้ พร้อมปุ่มกดฟังเสียงตัวอย่างประโยค
- **คำความหมายใกล้เคียง (Synonyms)** และ **คำตรงกันข้าม (Antonyms)** เพื่อเพิ่มพูนคลังคำศัพท์อย่างก้าวกระโดด (คลิกเพื่อค้นหาคำนั้นต่อได้ทันที)

### 2. 🔊 ระบบการออกเสียง 2 สำเนียง (US & UK Dual-Engine)
- **🇺🇸 สำเนียงอเมริกัน (American Accent - en-US)**: ออกเสียงชัดเจน พร้อมสัญลักษณ์สัทศาสตร์ IPA
- **🇬🇧 สำเนียงบริติช (British Accent - en-GB)**: ออกเสียงมาตรฐานอังกฤษ พร้อมสัญลักษณ์สัทศาสตร์ IPA
- **ระบบ Dual-Engine**: เล่นไฟล์เสียง MP3 แท้คุณภาพสูงจากพจนานุกรม และมีระบบสำรอง **Web Speech API** ที่ทำงานได้แบบออฟไลน์ 100%
- **โหมดฟังช้า (0.75x Slow)**: เหมาะสำหรับการจับจังหวะและสำเนียงการออกเสียงพยางค์อย่างละเอียด

### 3. 🏷️ จัดกลุ่มคำตามการใช้งาน (Usage Topics)
จัดกลุ่มคำศัพท์ตามบริบทการใช้งานจริงในชีวิตประจำวันและสายอาชีพ:
- 🏠 **Daily Life & Home**: ชีวิตประจำวัน, ครอบครัว, บ้านเรือน, กิจวัตร
- 💼 **Business & Work**: การทำงาน, ธุรกิจ, การเงิน, การค้า
- 💻 **Science & Technology**: วิทยาศาสตร์, เทคโนโลยี, คอมพิวเตอร์, ดิจิทัล
- 🎓 **Education & Academic**: การศึกษา, โรงเรียน, มหาวิทยาลัย, วิชาการ
- 🍽️ **Food & Dining**: อาหาร, เครื่องดื่ม, การทำอาหาร, ร้านอาหาร
- ✈️ **Travel & Transportation**: การเดินทาง, ยานพาหนะ, การท่องเที่ยว, โรงแรม
- 🩺 **Health & Medicine**: สุขภาพ, การแพทย์, ร่างกาย, การรักษา
- 😊 **Emotions & Personality**: อารมณ์, ความรู้สึก, บุคลิกภาพ, นิสัย
- 🌿 **Nature & Environment**: ธรรมชาติ, สัตว์, สิ่งแวดล้อม, สภาพอากาศ
- ⚖️ **Law, Society & Politics**: กฎหมาย, สังคม, การเมือง, ชุมชน
- 🎨 **Arts, Media & Entertainment**: ศิลปะ, บันเทิง, ภาพยนตร์, ดนตรี, สื่อ

### 4. 🗂️ บัตรคำศัพท์ 3 มิติ (3D Flashcards & Spaced Repetition)
- แอนิเมชันพลิกการ์ดแบบ 3D สมจริง (คลิกการ์ด หรือกดปุ่ม `Space`)
- ระบบประเมินการจดจำ (SRS):
  - 🔴 **ยาก (Hard) [กดเลข 1]**: วนกลับมาทบทวนซ้ำ
  - 🟡 **พอจำได้ (Good) [กดเลข 2]**: ปรับสถานะเป็น "กำลังเรียนรู้"
  - 🟢 **จำได้แม่นยำ (Easy) [กดเลข 3]**: ปรับสถานะเป็น "จำได้แล้ว"
- รองรับปุ่มลัดคีย์บอร์ดครบถ้วน: `Space` (พลิก), `ลูกศรซ้าย/ขวา` (ก่อนหน้า/ถัดไป), `U` (ฟังเสียง US), `B` (ฟังเสียง UK)

### 5. 🎯 โหมดแบบทดสอบ 4 รูปแบบ (Comprehensive Quiz)
- 🇬🇧 ➔ 🇹🇭 **อังกฤษ ➔ ไทย**: ดูคำศัพท์อังกฤษ เลือกคำแปลไทยที่ถูกต้อง
- 🇹🇭 ➔ 🇬🇧 **ไทย ➔ อังกฤษ**: ดูคำแปลไทย เลือกคำศัพท์ภาษาอังกฤษ
- 🎧 ➔ 📝 **แบบทดสอบการฟัง (Listening Quiz)**: ฟังเสียงพูดภาษาอังกฤษ แล้วทายคำศัพท์ที่ได้ยิน
- ⌨️ ➔ ✍️ **สะกดคำศัพท์ (Spelling Challenge)**: ฟังเสียงและดูความหมาย แล้วพิมพ์ตัวสะกดคำศัพท์ภาษาอังกฤษให้ถูกต้อง
- ระบบตัวเลือกหลอกอัจฉริยะ (Smart Distractors) ที่คัดเลือกมาจากชนิดของคำหรือระดับเดียวกัน
- มีระบบ Streak คูณคะแนน, เสียงประกอบเอฟเฟกต์ (Correct/Wrong chime), และสรุปรายงานผลพร้อมปุ่ม **"ทบทวนเฉพาะข้อที่ตอบผิด"**

### 6. 🎧 โหมดฟังคำศัพท์ต่อเนื่อง (Hands-Free Passive Listening)
- ฟังคำศัพท์อัตโนมัติแบบวนลูป เหมาะสำหรับฟังขณะขับรถ ทำงานบ้าน ออกกำลังกาย หรือก่อนนอน
- ตั้งค่าการเล่นได้ตามใจชอบ:
  - สลับฟัง US และ UK ต่อเนื่องกัน
  - อ่านออกเสียงคำแปลภาษาไทยต่อท้าย
  - ปรับความเร็วเสียง (0.8x - 1.2x) และระยะเวลาหน่วงระหว่างคำ (1.5 - 5 วินาที)
  - แอนิเมชัน Audio Visualizer แสดงคลื่นเสียงขณะกำลังเล่น

### 7. 📊 แดชบอร์ดสถิติ & สำรองข้อมูล (Progress & Dashboard)
- แสดงแถบเปอร์เซ็นต์ความคืบหน้าการจดจำคำศัพท์รวม
- กราฟสถิติแยกตามระดับ CEFR (A1 ถึง C1) และแยกตามหมวดหมู่การใช้งาน
- ระบบบันทึกจำนวนวันที่เข้าเรียนต่อเนื่อง (Daily Study Streak)
- ฟังก์ชัน **Export / Import Backup JSON** เพื่อสำรองข้อมูลและนำไปเปิดต่อในอุปกรณ์อื่นได้โดยข้อมูลไม่สูญหาย

### 8. 👤 ระบบลงทะเบียนและโปรไฟล์ส่วนตัว (100% Privacy & Zero Data Collection)
- **สร้างโปรไฟล์ง่ายๆ ได้ทันที**: กรอกชื่อหรือชื่อเล่น พร้อมเลือกรูปตัวแทน (Avatar) น่ารัก ๆ (เช่น 🦊, 🦉, 🦁, 🐼, 🚀, 🎓, ⚡, 🌟)
- **ตั้งเป้าหมายเฉพาะตัว**: กำหนดระดับเป้าหมาย CEFR (A1–C1) และจำนวนคำศัพท์ที่ต้องการเรียนรู้ในแต่ละวัน
- **สลับหลายโปรไฟล์ได้บนเครื่องเดียวกัน (Multi-Profile)**: สมาชิกในครอบครัวหรือเพื่อนสามารถสร้างโปรไฟล์แยกกันบนเบราว์เซอร์เดียวกันได้ โดยความคืบหน้าคำศัพท์และสถิติจะถูกแยกออกจากกันอย่างสมบูรณ์
- **🔒 ปลอดภัยสูงสุดและเคารพความเป็นส่วนตัว 100%**: ข้อมูลทั้งหมดถูกบันทึกในเบราว์เซอร์ของคุณ (LocalStorage) เท่านั้น ไม่มีการส่งข้อมูล ไม่เก็บข้อมูลผู้ใช้บนเซิร์ฟเวอร์ภายนอก และไม่มีการติดตามใด ๆ ทั้งสิ้น

## 🚀 วิธีนำขึ้น GitHub และเปิดใช้งาน GitHub Pages

เว็บนี้พัฒนาด้วย **Pure Vanilla HTML5, CSS3, และ JavaScript (Zero Dependencies)** ไม่จำเป็นต้องรันคำสั่ง build ใด ๆ สามารถโฮสต์บน **GitHub Pages** ได้ฟรีและเปิดใช้งานได้ในไม่กี่ขั้นตอน:

### ขั้นตอนที่ 1: สร้าง Repository บน GitHub
1. เข้าไปที่ [GitHub.com](https://github.com) แล้วเข้าสู่ระบบ
2. กดปุ่ม **"New repository"** (สร้างคลังข้อมูลใหม่)
3. ตั้งชื่อ Repository เช่น `oxford-5000-vocab-master`
4. เลือกเป็น **Public** (เพื่อให้เปิด GitHub Pages ฟรีได้)
5. กดปุ่ม **"Create repository"**

### ขั้นตอนที่ 2: อัปโหลดโค้ดขึ้น GitHub
หากใช้โปรแกรม **Git** ในเครื่อง (Command Prompt หรือ Terminal):
```bash
git init
git add .
git commit -m "Initial commit: Oxford 5000 Vocab Master Web App"
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
git push -u origin main
```
*(หรือหากใช้โปรแกรม **GitHub Desktop** / **VS Code** สามารถลากโฟลเดอร์นี้เข้าไปแล้วกด Commit & Push ได้ตามปกติ)*

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages (1 คลิก)
1. ในหน้า Repository บน GitHub ให้คลิกที่แท็บ **Settings** ด้านบน
2. ที่เมนูด้านซ้าย ให้คลิกที่ **Pages**
3. ภายใต้หัวข้อ **Build and deployment**:
   - **Source**: เลือก `Deploy from a branch`
   - **Branch**: เลือกสาขา `main` และโฟลเดอร์ `/ (root)`
4. กดปุ่ม **Save**
5. รอประมาณ 1–2 นาที GitHub จะสร้าง URL สำหรับเข้าใช้งานให้ทันที เช่น:
   ```text
   https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/
   ```
